اختبار إصلاح getClientSize

التحقق من إصلاح الخطأ: "Method Illuminate\Http\UploadedFile::getClientSize does not exist"

المشكلة الأصلية

الخطأ المكتشف:
Method Illuminate\Http\UploadedFile::getClientSize does not exist.
مكان الخطأ:

app/Services/FolderDuplicateDetectionService.php - السطر 430

الكود الخاطئ:
$fileSize = $file->getClientSize() ?? 0;
التأثير:
  • فشل في حفظ الملفات المكررة في قاعدة البيانات
  • الملفات يتم حفظها في temp storage ولكن temp_path يبقى NULL
  • رسائل خطأ في Laravel logs
  • النظام لا يستطيع تتبع الملفات المكررة بشكل صحيح

الحل المطبق

الإصلاح:

استبدال getClientSize() بطريقة بديلة آمنة

الكود الجديد:
// التحقق من حجم الملف بأمان مع timeout
try {
    $fileSize = $file->getSize();
} catch (\Exception $e) {
    Log::warning('Could not get file size, using alternative method', [
        'file' => $originalName,
        'error' => $e->getMessage()
    ]);
    // استخدام حجم الملف من طريقة بديلة
    try {
        $fileSize = filesize($file->getPathname()) ?: 0;
    } catch (\Exception $e2) {
        Log::warning('Failed to get file size via alternative method', [
            'file' => $originalName,
            'error' => $e2->getMessage()
        ]);
        $fileSize = 0;
    }
}
التحسينات:
  • استخدام $file->getSize() الصحيح
  • طريقة بديلة مع filesize()
  • معالجة أخطاء شاملة
  • logging مفصل للتشخيص
  • fallback إلى 0 في أسوأ الحالات
