خطأ SQL:
SQLSTATE[42S22]: Column not found: 1054

الأعمدة الخاطئة:
  • file_id_number ← غير موجود
  • data_id_number ← غير موجود
  • original_name ← اسم خاطئ
  • stored_name ← اسم خاطئ
  • storage_location ← غير موجود
✅ الحل المطبق:
التصحيحات:
  • record_number ← رقم سجل فريد
  • person_identity_number ← رقم الهوية (null للـ Excel)
  • original_file_name ← اسم الملف الأصلي
  • stored_file_name ← اسم الملف المحفوظ
  • source ← 'direct_upload'
رقم السجل الجديد:
EXL_YmdHis_HASH6
📊 بنية الجدول الصحيحة:
اسم العمود النوع الوصف المثال

stored_file_name string اسم الملف المحفوظ 2025-07-12_02-55-56_test.xlsx
original_file_name string اسم الملف الأصلي test.xlsx
file_path text مسار الملف documents/excel/2025-07-12_02-55-56_test.xlsx
source enum مصدر الرفع direct_upload
