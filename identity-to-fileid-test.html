تحويل رقم الهوية إلى file_id_number

نظام تحويل أسماء المجلدات (أرقام الهوايا) إلى أرقام الملفات باستخدام الخوارزمية المعتمدة

الخوارزمية المحدثة تكامل قاعدة البيانات دعم المجلدات المتعددة

كيفية عمل النظام الجديد

الخطوة 1
رفع المجلد الرئيسي

اختار مجلد يحتوي على مجلدات فرعية أسماؤها أرقام هوايا

الخطوة 2
استخراج أرقام الهوايا

النظام يقرأ أسماء المجلدات الفرعية كأرقام هوايا

الخطوة 3
البحث في قاعدة البيانات

يبحث عن file_id_number المقابل لكل رقم هوية

الخطوة 4
إنشاء file_id_number جديد

إذا لم يوجد، ينشئ رقم جديد بالخوارزمية المعتمدة

الخطوة 5
تحويل المسارات

يستبدل أسماء المجلدات بأرقام الملفات الجديدة

الخطوة 6
حفظ النتائج

يحفظ الصور مع المسارات المحدثة

🔍 دالة البحث عن file_id_number
function getFileIdByIdentityNumber($identityNumber) { // البحث في جدول data $record = DB::table('data') ->where('person_id', $identityNumber) ->orWhere('guardian_id', $identityNumber) ->first(); if ($record && $record->file_id_number) { return $record->file_id_number; } // إنشاء رقم جديد بالخوارزمية المعتمدة return generateFileIdFromDataTable(); }
⚙️ دالة إنشاء رقم جديد
function generateFileIdFromDataTable() { return DB::transaction(function () { // جلب آخر file_id_number $lastFileId = DB::table('data') ->whereNotNull('file_id_number') ->orderByRaw('CAST(file_id_number as UNSIGNED) DESC') ->value('file_id_number'); // حساب الرقم التالي $nextNumber = $lastFileId ? ((int)$lastFileId + 1) : 1; // إرجاع الرقم مع 6 خانات return str_pad($nextNumber, 6, '0', STR_PAD_LEFT); }); }

اختبار النظام

خطوات الاختبار:
  1. إنشاء مجلد رئيسي على جهازك
  2. إنشاء مجلدات فرعية بأسماء أرقام هوايا (مثل: 1234567890، 9876543210)
  3. وضع صور داخل كل مجلد فرعي
  4. فتح النظام واختيار "مجلد + صور متعددة"
  5. اختيار المجلد الرئيسي
  6. مراقبة Console للنتائج
ما ستراه في Console:
  • 🔄 تحويل رقم الهوية إلى رقم الملف
  • 📊 خريطة التحويل الكاملة
  • ✅ حالة كل ملف تم معالجته
