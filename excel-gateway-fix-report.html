تم إصلاح مشكلة بوابة Excel

التعديلات المنجزة:
  • ✅ تصحيح قيم enable_excel_import لتكون منطقية (1/0 بدلاً من true/false)
  • ✅ تصحيح قيم header_row و skip_empty_rows و validate_data
  • ✅ تصحيح route names للمطابقة مع admin.file.excel.gateway و admin.file.excel.upload
  • ✅ إضافة headers مطلوبة (Accept و X-Requested-With)
🔧 ما تم إصلاحه:
المشكلة: enable_excel_import يُرسل كنص 'true'/'false'
الحل: تغيير إلى '1'/'0'
المشكلة: checkbox values ترسل كـ true/false
الحل: تحويل إلى '1'/'0' للتوافق مع Laravel validation
المشكلة: route names غير متطابقة
الحل: استخدام admin.file.excel.* routes
🧪 اختبار النظام:
اختبار بوابة Excel المباشرة اختبار الواجهة المتقدمة
📋 خطوات الاختبار:
  1. افتح بوابة Excel
  2. اختر نوع المعالجة (حفظ فقط أو استيراد)
  3. ارفع ملف Excel/CSV
  4. تأكد من عدم ظهور خطأ "يجب أن تكون قيمة enable excel import صحيحة أو خاطئة"
التعديلات التقنية:
في excelSaveFileAndInsert.blade.php: 
// قبل الإصلاح
formData.append('enable_excel_import', 'true');

// بعد الإصلاح
formData.append('enable_excel_import', '1');
في Controller validation: 
'enable_excel_import' => 'nullable|boolean',
// الآن سيقبل: 1, 0, true, false, "1", "0"
