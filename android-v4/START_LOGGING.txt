🌐 ملاحظة: استخدام V (Verbose) يعرض:
───────────────────────────────────────────────────────────────────────────────

✅ Log.v() - Verbose
✅ Log.d() - Debug
✅ Log.i() - Info
✅ Log.w() - Warning
✅ Log.e() - Error
✅ console.log() من JavaScript
✅ console.error() من JavaScript
✅ console.warn() من JavaScript


═══════════════════════════════════════════════════════════════════════════════
📊 شرح المعاملات:
═══════════════════════════════════════════════════════════════════════════════

-v threadtime          : يعرض الوقت والـThread ID
-v color              : يضيف ألوان للأخطاء (اختياري)
MainActivity:E        : فقط ERROR logs من MainActivity
UploadServicePlugin:E : فقط ERROR logs من Plugin
AutoUploadApp:E       : فقط ERROR logs من Application
chromium:I            : INFO من Chrome WebView (JavaScript console)
Console:I             : JavaScript console.log()
*:S                   : Silent - إخفاء كل شيء آخر
