🔗 نظام ربط جدول المتوفين مع جدول الولي

شرح آلية ربط DeadPepole مع Data من خلال مطابقة أرقام الهوية

🎯 الهدف من النظام

  • المشكلة الأصلية: جدول DeadPepole يحتوي على re_file_id لا يتطابق مع file_id_number في جدول Data
  • الحل: مطابقة re_file_id مع data_id_number في جدول Data
  • النتيجة: استبدال re_file_id بـ file_id_number الصحيح لضمان الربط السليم

📊 مثال عملي على البيانات

جدول Data (الولي الأمر):

file_id_number data_id_number data_first_name data_family_name
000123 1234567890 أحمد العلي
000124 9876543210 فاطمة الحسن

ملف Excel للمتوفين (قبل المعالجة):

رقم ملف الأب اسم الأب الأول رقم هوية الأب تاريخ وفاة الأب
1234567890 والد أحمد 1111111111 2020-01-15
9876543210 والد فاطمة 3333333333 2019-11-10

❌ re_file_id يحتوي على أرقام هوية بدلاً من أرقام ملفات

🔄 آلية المعالجة

الخطوة 1: قراءة ملف Excel وتحديد re_file_id الأصلي
$originalReFileId = $data['re_file_id']; // "1234567890"
الخطوة 2: البحث في جدول Data عن تطابق في data_id_number
$matchingRecord = DB::table('data') ->select('file_id_number', 'data_id_number') ->where('data_id_number', $originalReFileId) ->first(); // النتيجة: file_id_number = "000123" for data_id_number = "1234567890"
الخطوة 3: استبدال re_file_id بـ file_id_number المطابق
if ($matchingRecord) { $data['re_file_id'] = $matchingRecord->file_id_number; // "000123" // تسجيل عملية الاستبدال للمراجعة }
الخطوة 4: حفظ البيانات مع الربط الصحيح
// يتم حفظ السجل في dead_people مع re_file_id = "000123" // الآن يمكن الربط مع جدول Data بشكل صحيح

📋 النتيجة النهائية

جدول DeadPepole (بعد المعالجة):

re_file_id father_first_name father_id father_death_date مرتبط بـ Data
000123 والد أحمد 1111111111 2020-01-15 ✅ أحمد العلي
000124 والد فاطمة 3333333333 2019-11-10 ✅ فاطمة الحسن

✅ re_file_id الآن يحتوي على أرقام ملفات صحيحة تربط مع جدول Data

🔍 مقارنة قبل وبعد

❌ قبل التحسين

re_file_id = "1234567890" (رقم هوية) ↓ لا يمكن الربط مع Data.file_id_number ↓ علاقة Eloquent لا تعمل

✅ بعد التحسين

re_file_id = "000123" (رقم ملف) ↓ ربط مباشر مع Data.file_id_number ↓ علاقة Eloquent تعمل بشكل مثالي

📊 إحصائيات الاستبدال

تتبع العمليات: يتم تسجيل كل عملية استبدال في:
  • الـ logs: Laravel.log مع تفاصيل كاملة
  • إحصائيات الجلسة: getFileIdReplacements() للمراجعة الفورية
  • تفاصيل الاستبدال: الرقم الأصلي، الرقم الجديد، وتفاصيل الأب والأم

🎯 الفوائد المحققة

  • ✅ ربط صحيح: جميع سجلات DeadPepole مرتبطة بشكل صحيح مع Data
  • ✅ علاقات Eloquent: تعمل جميع العلاقات بين الجداول
  • ✅ تتبع شامل: تسجيل جميع عمليات الاستبدال
  • ✅ معالجة الأخطاء: تحذيرات عند عدم وجود تطابق
  • ✅ مرونة: يعمل مع ملفات Excel و CSV

⚠️ نقاط مهمة

  • شرط أساسي: يجب أن تكون بيانات الولي موجودة في جدول Data قبل استيراد المتوفين
  • دقة البيانات: أرقام الهوية يجب أن تكون متطابقة تماماً
  • معالجة الأخطاء: في حالة عدم وجود تطابق، يتم رفض السجل مع رسالة خطأ واضحة
  • النسخ الاحتياطي: يُنصح بعمل نسخة احتياطية قبل عمليات الاستيراد الكبيرة
