دليل المجلدات والصور

تعلم كيفية إدراج المجلدات مع الصور والملفات بطريقة احترافية

إخفاء حقل رقم الملف Console.log للأرقام دعم المجلدات

1. إخفاء حقل رقم الملف

✅ تم التطبيق

حقل رقم الملف أصبح مخفياً، ولكن يعمل في الخلفية

رؤية الأرقام في Console

افتح Developer Tools (F12) وانظر إلى Console لرؤية:

  • 🔢 رقم الملف المولد من قاعدة البيانات
  • 🔄 رقم الملف التلقائي المؤقت
  • 📊 تفاصيل إضافية عن كل رقم
console.log('🔢 رقم الملف:', '001430'); console.log('📄 التفاصيل:', { recordNumber: '001430', source: 'database' });

2. إدراج المجلدات

اختيار مجلد كامل
1
انقر على "اختيار مجلد"
الزر الأزرق الجديد
2
اختر أي مجلد من جهازك
سيتم رفع جميع الملفات بداخله
3
سيحافظ على البنية الأصلية
مع عرض مسار كل ملف
مجلد الصور المخصص
1
انقر على "مجلد + صور متعددة"
الزر الأصفر المخصص للصور
2
اختر مجلد يحتوي على صور
يقبل JPG, PNG, GIF, WebP
3
معالجة مطورة للصور
ضغط تلقائي وتحسين الجودة

3. الميزات التقنية المضافة

حفظ البنية

يحافظ على ترتيب المجلدات والملفات كما هي في جهازك

المسارات النسبية

يعرض مسار كل ملف داخل المجلد المختار

معالجة متقدمة

ضغط تلقائي للصور ومعالجة مخصصة لكل نوع ملف

4. أمثلة عملية من Console

مثال: رفع مجلد مستندات
📁 تم اختيار مجلد يحتوي على: 15 ملف 📄 قائمة الملفات: [ { name: "report.pdf", path: "documents/reports/report.pdf", size: 2048576, type: "application/pdf" }, { name: "invoice.xlsx", path: "documents/invoices/invoice.xlsx", size: 1024000, type: "application/vnd.openxml..." } ]
مثال: رفع مجلد صور
🖼️ تم اختيار مجلد صور يحتوي على: 8 صورة 🎨 قائمة الصور: [ { name: "photo1.jpg", path: "photos/vacation/photo1.jpg", size: 3145728, type: "image/jpeg" }, { name: "logo.png", path: "photos/assets/logo.png", size: 512000, type: "image/png" } ]
حالة النظام الشاملة
✅ تمت معالجة 23 ملف من المجلد 📊 حالة النظام: { totalFiles: 23, folderStructure: { "documents/reports": ["report1.pdf", "report2.pdf"], "documents/invoices": ["inv001.xlsx", "inv002.xlsx"], "photos/vacation": ["photo1.jpg", "photo2.jpg"], "photos/assets": ["logo.png", "icon.svg"] } }

5. نصائح مهمة للاستخدام

تنبيهات
  • استخدم Chrome أو Edge للحصول على أفضل دعم للمجلدات
  • تأكد من أن المجلد لا يحتوي على ملفات كبيرة جداً
  • راقب Console لرؤية تقدم المعالجة
للحصول على أفضل أداء
  • ابدأ بمجلدات صغيرة للتجربة
  • استخدم خيار "ضغط الصور" للصور الكبيرة
  • راجع معاينة الملفات قبل الرفع النهائي
