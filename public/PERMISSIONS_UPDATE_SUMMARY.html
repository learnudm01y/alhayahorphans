🚀كيفية الاستخدام

الخطوة 1: أضف السكريبت في صفحة تسجيل الدخول (أو index.html):

<head> <script src="/js/permissions-manager.js"></script> </head>

الخطوة 2: استدعي النظام بعد نجاح تسجيل الدخول:

function onLoginSuccess() { // طلب جميع الصلاحيات بشكل متسلسل PermissionsManager.requestAllPermissions((result) => { console.log('✅ تم الانتهاء:', result); // الانتقال للصفحة الرئيسية window.location.href = '/dashboard'; }); }
💡 نصيحة: يمكنك أيضاً استدعاء النظام عند بدء التطبيق للتحقق من الصلاحيات.
