الآن جميع الصلاحيات الخمس تظهر بشكل متسلسل - واحدة تلو الأخرى.

🐛 المشكلة التي كانت موجودة

ما كان يحدث:
  • يظهر فقط طلب صلاحية الإشعارات 🔔
  • باقي الصلاحيات (الكاميرا، الصوت، التخزين، البطارية) لا تظهر أبداً ❌
  • المستخدم يوافق على الإشعارات ثم لا يحدث شيء

السبب التقني:

كان النظام يحاول طلب جميع الصلاحيات دفعة واحدة باستخدام requestPermissionForAlias() من Capacitor، والذي لا يعمل بشكل صحيح مع الطلبات المتسلسلة.

✨ الحل المطبق

التغيير الأساسي:

استخدام ActivityCompat.requestPermissions() مباشرة من Android بدلاً من Capacitor API.

كود الحل:

private void requestCameraPermission() { if (checkCameraPermission()) { // الصلاحية ممنوحة بالفعل - إرسال فوري JSObject result = new JSObject(); result.put("granted", true); result.put("permission", "camera"); savedCall.resolve(result); savedCall = null; } else { // ✅ طلب الصلاحية من المستخدم ActivityCompat.requestPermissions( getActivity(), new String[]{Manifest.permission.CAMERA}, REQUEST_CAMERA_PERMISSION ); // سيتم استقبال النتيجة في: // handleRequestPermissionsResult() } }

🔄 كيف يعمل الآن (متسلسل صحيح)

السيناريو الكامل:

المستخدم يضغط "منح الصلاحية"
JavaScript يرسل طلب للـ Plugin
Plugin يطلب صلاحية الإشعارات
Android يعرض dialog: "السماح بالإشعارات؟"
المستخدم يضغط "السماح" ✅
handleRequestPermissionsResult() يستقبل النتيجة
savedCall.resolve() يرسل النتيجة لـ JavaScript
JavaScript: currentIndex++ (الانتقال للتالي)
updateUI() تحديث الواجهة
الآن يظهر طلب الكاميرا 📷
... وهكذا حتى تكتمل جميع الصلاحيات

🧪 كيفية الاختبار

1. إزالة النسخة القديمة:

adb uninstall com.aso.app

2. تثبيت APK الجديد:

adb install "I:\unit test\alhayahorphans\ASO - Copy\android\app\build\outputs\apk\debug\app-debug.apk"

3. مراقبة اللوجات:

adb logcat -s PermissionsManager:* MainActivity:*

4. استدعاء النظام في التطبيق:

PermissionsManager.requestAllPermissions((result) => { console.log('✅ تم الانتهاء:', result); });
