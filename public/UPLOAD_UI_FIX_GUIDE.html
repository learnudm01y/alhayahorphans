🔥 حل المشكلة اللعينة 🔥

دليل تحديث واجهة الملفات المعلقة في الوقت الفعلي

❌ المشكلة

الملفات تُرفع بنجاح لكن الواجهة لا تتحدث!

  • ✅ FileSyncWorker يرفع الملف بنجاح (200 OK)
  • ✅ Database يتحدث إلى STATUS_COMPLETED
  • ❌ لكن عداد "الملفات المعلقة" يبقى جامد
  • ❌ upload.html لا تُظهر "تم الرفع"
  • ❌ index.html الإحصائيات لا تتغير

⚠️ مشكلة Foreground Service

E FileSyncWorker: ❌ Failed to set foreground: ForegroundServiceStartNotAllowedException W FileSyncWorker: ⚠️ Continuing WITHOUT foreground service - uploads may be killed!

السبب: Android يمنع Worker من التحول إلى Foreground Service! قد يُقتل Worker قبل أن يُرسل event إلى JavaScript.

✅ الحل الشامل

تم إضافة 3 إصلاحات:

  • ✅ Foreground Service Permissions في AndroidManifest.xml
  • ✅ JavaScript Event Listener نظام متكامل
  • ✅ Auto-Refresh كل 30 ثانية لضمان التحديث

📝 خطوات التطبيق

1

إضافة JavaScript في index.html

أضف هذا الكود قبل نهاية </body>:

<!-- 📡 Upload Status Real-Time Sync --> <script src="/js/upload-status-sync.js"></script> <script> // Optional: Manual stats refresh button function refreshUploadStats() { if (window.UploadStatusSync) { window.UploadStatusSync.fetchStats(); window.UploadStatusSync.showToast('🔄 جاري تحديث الإحصائيات...', 'info'); } } </script>
2

إضافة JavaScript في upload.html

نفس الكود - أضفه قبل </body>:

<!-- 📡 Upload Status Real-Time Sync --> <script src="/js/upload-status-sync.js"></script> <!-- Optional: Add refresh button in upload.html --> <button class="btn btn-primary" onclick="refreshUploadStats()"> 🔄 تحديث الإحصائيات </button>
3

إضافة عنصر العداد (إن لم يكن موجوداً)

تأكد من وجود أحد هذه العناصر في HTML:

<!-- خيار 1: عداد بسيط --> <div class="stat-card"> <h5>ملفات معلقة</h5> <h2 id="stat-files">0</h2> </div> <!-- خيار 2: إحصائيات كاملة --> <div class="stats-container"> <div>معلق: <span id="stat-pending">0</span></div> <div>جاري الرفع: <span id="stat-uploading">0</span></div> <div>مكتمل: <span id="stat-completed">0</span></div> <div>فشل: <span id="stat-failed">0</span></div> </div>
4

Build APK جديد

افتح PowerShell وقم بالتالي:

cd "i:\unit test\alhayahorphans\ASO - Copy\android" .\gradlew assembleDebug --quiet

الملف سيكون في:

android\app\build\outputs\apk\debug\app-debug.apk
5

تثبيت APK

احذف النسخة القديمة وثبت الجديدة:

adb uninstall com.aso.app adb install app\build\outputs\apk\debug\app-debug.apk
6

  4. افتح Console في DevTools

عند نجاح الرفع:

🎯 المميزات المضافة

  • 📡 Real-Time Events: JavaScript يستقبل أحداث فورية من Java
  • 🔄 Auto-Refresh: تحديث تلقائي كل 30 ثانية
  • 🔔 Toast Notifications: إشعارات عند نجاح/فشل الرفع
  • 🎨 Animations: تأثيرات بصرية (flash, pulse, shake)
  • 📊 Full Stats API: getUploadStats() للحصول على جميع الإحصائيات
  • 🗑️ Auto-Remove: الملفات الناجحة تُحذف تلقائياً بعد 3 ثوانٍ
  • 🛡️ Foreground Service Fix: صلاحيات جديدة لمنع قتل Worker

🛡️ الصلاحيات المضافة

تم إضافة في AndroidManifest.xml:

  • FOREGROUND_SERVICE
  • FOREGROUND_SERVICE_DATA_SYNC
  • POST_NOTIFICATIONS (Android 13+)
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS

📝 هذه الصلاحيات تضمن:

  • ✅ Worker يمكنه التحول إلى Foreground Service
  • ✅ Android لن يقتل Worker أثناء الرفع
  • ✅ الإشعارات تعمل بشكل صحيح

🔧 تحديث يدوي (للمستخدم)

⚙️ في حال لم يتحدث العداد تلقائياً:

يمكن للمستخدم تحديث الإحصائيات يدوياً:

  1. من Console:
    window.UploadStatusSync.fetchStats()
  2. أو أضف زر في الواجهة:
    <button onclick="window.UploadStatusSync.fetchStats()"> 🔄 تحديث الإحصائيات </button>

🔍 استكشاف الأخطاء

1. Event لا يصل إلى JavaScript

الحل:

  • افتح Chrome DevTools Console
  • تأكد من ظهور: ✅ Event listener registered successfully
  • إذا لم يظهر → تحقق من تحميل upload-status-sync.js

2. العداد لا يتحدث

الحل:

  • تحقق من وجود id="stat-files" في HTML
  • أو أي من: pending-files-count, files-counter
  • جرب التحديث اليدوي: window.UploadStatusSync.fetchStats()

3. Foreground Service لا يعمل

الحل:

  • تأكد من build APK جديد بعد تعديل AndroidManifest
  • احذف التطبيق القديم تماماً قبل التثبيت
  • تحقق من Logs - يجب أن ترى: ✅ Worker successfully promoted to FOREGROUND SERVICE

📚 JavaScript API Reference

// جلب الإحصائيات وتحديث UI window.UploadStatusSync.fetchStats() // بدء التحديث التلقائي (كل 30 ثانية) window.UploadStatusSync.startAutoRefresh() // إيقاف التحديث التلقائي window.UploadStatusSync.stopAutoRefresh() // إظهار رسالة Toast window.UploadStatusSync.showToast('رسالة', 'success') // success / error / info // الحصول على الإحصائيات الحالية const stats = window.UploadStatusSync.getStats() // {pending: 0, uploading: 0, completed: 1, failed: 0, total: 1} // التحقق من حالة النظام const isActive = window.UploadStatusSync.isActive() // true = Event listener مفعل
