🧪 اختبار نظام توليد أرقام المرفقات

اختبار وظيفة generateUniqueAttachmentRecordNumber وتطبيقها في النظام

🎯 الهدف من النظام:

  • توليد رقم فريد لكل مرفق بالبادئة exc_
  • ضمان عدم التضارب مع الأرقام الموجودة
  • استخدام جدول reserved_codes للحماية من race conditions
  • تطبيق النظام على جميع أنواع الملفات (Excel, PDF, Images)

🔧 الوظائف المطبقة:

// 1. في global_helper.php function generateUniqueAttachmentRecordNumber($sessionId = null): string // 2. في UnifiedFileManagementController.php - saveDocumentRecord() ← للمستندات (PDF/Excel) - saveExcelFileRecord() ← لملفات Excel - saveImageRecordWithCustomName() ← للصور

🧪 اختبارات متاحة:

📊 نتائج الاختبار:

📋 مثال على تدفق العمل:

1. مستخدم يرفع ملف Excel ↓ 2. يتم استدعاء generateUniqueAttachmentRecordNumber() ↓ 3. يتم البحث في enhanced_attachments و reserved_codes ↓ 4. يتم توليد رقم جديد مثل: exc_000001 ↓ 5. يتم حجز الرقم في reserved_codes ↓ 6. يتم حفظ الملف مع الرقم الجديد

📝 بيانات اختبار نموذجية:

// أرقام محتملة: exc_000001, exc_000002, exc_000003, ... // بنية البيانات في enhanced_attachments: { "id": 1, "record_number": "exc_000001", "original_file_name": "sample.xlsx", "file_type": "excel", "stored_file_path": "/storage/documents/excel/sample.xlsx", "created_at": "2025-07-12 12:00:00" }
