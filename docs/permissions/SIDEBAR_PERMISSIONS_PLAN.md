# Sidebar Permissions Matrix

هذا الملف يحدد صلاحيات روابط الـSidebar التي تم تطبيقها حالياً كمرحلة أولى من مشروع إدارة الصلاحيات.

## 1) مبادئ المرحلة الحالية

- كل رابط Sidebar مرتبط بصلاحية منفصلة (Granular Control).
- كل مجموعة (Accordion) تظهر فقط عند امتلاك أي صلاحية ضمن المجموعة.
- مستخدم `admin` يملك تجاوزاً شاملاً للصلاحيات عبر `Gate::before` في `AuthServiceProvider`.
- إنشاء الصلاحيات أصبح Idempotent عبر `firstOrCreate`.

## 3) المرحلة التالية (System-wide)

الخطوة القادمة: حماية الـRoutes والعمليات (Controller Actions) بنفس خريطة الصلاحيات، وليس فقط إخفاء روابط الواجهة.

اقتراح التنفيذ:
1. بناء مصفوفة صفحة -> صلاحيات CRUD + صلاحيات العمليات الخاصة.
2. تطبيق Middleware `permission:` على routes في `routes/admin.php`.
3. تدقيق Controllers الحرجة (store/update/delete/export/import/upload).
4. إنشاء تقرير تغطية الصلاحيات لكل صفحة.
