# نسخة Offline للاختبار - تطبيق الكفالات

## 📱 الوصف

هذه نسخة offline من تطبيق إدارة الكفالات للاختبار في المتصفح بدون الحاجة للاتصال بالسيرفر.

## 🚀 كيفية الاستخدام

### الطريقة 1: فتح مباشر في المتصفح
1. افتح الملف `test-offline.html` مباشرة في المتصفح
2. أو افتح `login.html` للدخول عبر صفحة تسجيل الدخول

### الطريقة 2: استخدام خادم محلي (موصى به)
```bash
# باستخدام Python
cd mobile-app-offline
python -m http.server 8080

# أو باستخدام PHP
php -S localhost:8080

# أو باستخدام Node.js (بعد تثبيت serve)
npx serve -p 8080
```

ثم افتح في المتصفح: `http://localhost:8080/test-offline.html`

| 1002 | breadwinner | سامي فؤاد عبدالله المعيل | (نفسه) |
| 1003 | deceased_father | خالد إبراهيم محمد الشهيد | - |
| 1004 | deceased_mother | فاطمة أحمد محمود المتوفية | - |

| 1006 | family_member | سارة خالد محمود العائلة | خالد محمود أحمد العائلة |

## ⚙️ الميزات

### ما يعمل:
- ✅ تسجيل الدخول (بدون تحقق من السيرفر)
- ✅ عرض قائمة الكفالات
- ✅ عرض تفاصيل الكفالة
- ✅ تعديل البيانات (تحفظ محلياً في localStorage)
- ✅ البحث والتصفية
- ✅ الخطوط العربية والأيقونات

### ما لا يعمل:
- ❌ المزامنة مع السيرفر
- ❌ رفع الصور إلى السيرفر
- ❌ Google Drive backup
- ❌ الإشعارات

## 🔧 التعديلات للـ Offline

### api-service.js
- تم إضافة `offlineMode: true`
- جميع الطلبات تُرجع بيانات وهمية
- التحديثات تُحفظ في `localStorage`

### sync-service.js
- تم تبسيط الكود للعمل في المتصفح
- إزالة Capacitor plugins
- البيانات تُخزن في IndexedDB و localStorage

## 📝 ملاحظات

- هذه النسخة للاختبار فقط
- التغييرات تُحفظ محلياً ولا ترسل للسيرفر
- لإعادة البيانات للأصل، اضغط "إعادة تعيين البيانات" أو امسح localStorage

## 🐛 حل المشاكل

### الأيقونات لا تظهر
تأكد من وجود مجلد `fonts/` وملفات الخطوط

### الصفحات لا تعمل
استخدم خادم محلي بدلاً من فتح الملفات مباشرة

### خطأ في تحميل البيانات
امسح localStorage وأعد تحميل الصفحة
