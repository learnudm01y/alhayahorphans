# 📁 نظام رفع المجلدات مع تحويل الهوية

## 🎯 نظرة عامة

تم تطوير نظام شامل لرفع المجلدات التي تحتوي على مجلدات فرعية بأسماء أرقام الهوية، مع تحويل هذه الأرقام تلقائياً إلى `file_id_number` باستخدام الخوارزمية المعتمدة من `global_helper.php`.

## ✨ المميزات الرئيسية

### 🔄 التحويل التلقائي
- **تحويل أرقام الهوية**: يتم تحويل أسماء المجلدات (أرقام الهوية) تلقائياً إلى `file_id_number`
- **خوارزمية معتمدة**: استخدام الدوال المعتمدة من `global_helper.php`
- **فحص صحة الهوية**: التحقق من صحة أرقام الهوية قبل التحويل

### 📂 إدارة المجلدات
- **رفع مجلدات متعددة**: دعم رفع مجلدات تحتوي على مجلدات فرعية
- **حفظ البنية**: الحفاظ على بنية المجلدات الأصلية
- **أنواع ملفات متعددة**: دعم الصور، المستندات، ملفات Excel

### 🎨 واجهة متقدمة
- **سحب وإفلات**: واجهة سهلة لسحب وإفلات المجلدات
- **معاينة فورية**: عرض محتويات المجلدات قبل الرفع
- **سجل مفصل**: تتبع جميع العمليات في الكونسول

## 🏗️ الهيكل التقني

### 📁 الملفات الرئيسية

```
app/
├── Helpers/

├── Http/Controllers/

resources/views/file-management/
```

### 🔧 المكونات المطورة

#### 1. global_helper.php
```php
// دوال جديدة مضافة:
- getFileIdByIdentityNumber()      // تحويل الهوية إلى file_id
- validateIdentityNumber()         // فحص صحة الهوية  
- bulkValidateIdentityNumbers()    // فحص متعدد للهويات
- generateFileIdFromDataTable()    // توليد file_id جديد
```

#### 2. UnifiedFileManagementController.php
```php
// دوال جديدة مضافة:
- processFolderUpload()           // معالجة رفع المجلدات
- generateRecordNumber()          // توليد رقم ملف جديد
- processFileWithMapping()        // معالجة ملف مع التحويل
- processExcelWithMapping()       // معالجة Excel مع التحويل
```

#### 3. advanced-interface.blade.php
```javascript
// دوال JavaScript جديدة:
- handleFolderSelect()           // اختيار المجلدات
- handleImagesWithFolderSelect() // اختيار مجلد صور
- uploadFolderFile()             // رفع المجلدات مع التحويل
- processFolderFiles()           // معالجة ملفات المجلدات
```

## 🚀 طريقة الاستخدام

### 1. الوصول للنظام
```
http://localhost:8000/file-manager
```

### 2. رفع مجلد
1. انقر على زر "اختيار مجلد" أو "مجلد + صور متعددة"
2. اختر المجلد الذي يحتوي على مجلدات فرعية بأسماء أرقام الهوية
3. سيتم تحليل البنية تلقائياً وعرض المعاينة
4. انقر "بدء الرفع" لتنفيذ العملية

### 3. مراقبة العملية
- تتم طباعة تفاصيل العملية في الكونسول
- عرض عدد الملفات المعالجة
- إظهار التحويلات التي تمت
- تتبع حالة كل ملف

## 📋 مثال على البنية المدعومة

```
المجلد_الرئيسي/
├── 1234567890/           # رقم هوية صالح
│   ├── صورة1.jpg
│   ├── صورة2.png
│   └── مستند.pdf
├── 0987654321/           # رقم هوية صالح
│   ├── ملف1.docx
│   └── ملف2.xlsx
└── مجلد_عادي/            # سيتم تجاهله
    └── ملف.txt
```

**النتيجة:**
- `1234567890` → `FILE_2025_001`
- `0987654321` → `FILE_2025_002`

## 🔧 التكامل مع قاعدة البيانات

### جداول مستخدمة:
- `data`: للحصول على `file_id_number`
- `enhanced_attachments`: لحفظ الملفات المرفوعة
- `reserved_codes`: لضمان عدم التكرار

### خوارزمية التحويل:
1. البحث عن رقم الهوية في جدول `data`
2. إذا وُجد: استخدام `file_id_number` الموجود
3. إذا لم يوجد: إنشاء `file_id_number` جديد
4. حفظ الملفات مع الرقم الجديد
