✅ المشاكل التي تم حلها:

1. مشكلة "Undefined array key 'original_file_id_from_excel'"

السبب: تضارب في أسماء المفاتيح في array الاستبدالات

الحل: توحيد أسماء المفاتيح في جميع أنحاء الكود

// قبل الإصلاح
$this->fileIdReplacements[] = [
    'original' => $originalFileId,    // مفتاح خاطئ
    'new' => $newFileId,             // مفتاح خاطئ
];

// بعد الإصلاح
$this->fileIdReplacements[] = [
    'original_file_id_from_excel' => $originalFileId,
    'new_file_id_number' => $newFileId,
    'identity_number' => $identityNumber,
    'replacement_method' => $method
];

2. مشكلة تكرار أرقام الملفات (Duplicate file IDs)

السبب: دالة generateFileIdFromDataTable ترجع نفس الرقم لجميع السجلات

الحل: إضافة عداد محلي + استخدام خوارزمية محسنة

// النظام الجديد
private int $localFileIdCounter = 0;

private function generateFileIdFallback(): string
{
    $this->localFileIdCounter++;
    $nextId = ($maxFileId ?? 0) + $this->localFileIdCounter;
    return str_pad($nextId, 7, '0', STR_PAD_LEFT);
}

3. تحسين تتبع طرق التوليد

التحسين: إضافة خاصية $lastUsedMethod لتتبع الطريقة المستخدمة

private string $lastUsedMethod = 'unknown';

// يتم تحديثها في كل استدعاء
$this->lastUsedMethod = 'generateFileIdFallback';

  • ✅ الأرقام الأصلية ستحفظ في original_file_id_from_excel

  • ✅ تقارير مفصلة وصحيحة
  • ✅ لا توجد أخطاء "Undefined array key"
  • ✅ لا يوجد تكرار في أرقام الملفات
