=====================================
حل مشكلة Foreign Key - خطوات سريعة
=====================================

الطريقة الأسهل (موصى بها):
----------------------------

1. رفع ملف fix_foreign_key.php إلى المجلد الرئيسي
2. تشغيله من terminal:

```bash
cd /var/www/html/alhayahorphans
php fix_foreign_key.php
```

أو من المتصفح:
http://your-domain.com/fix_foreign_key.php

----------------------------

الطريقة البديلة (SQL مباشرة):
----------------------------

تسجيل الدخول إلى MySQL:

```bash
mysql -u root -p aso
```

ثم تنفيذ:

```sql
ALTER TABLE association_employees MODIFY COLUMN sponsor_id BIGINT UNSIGNED NULL;
DELETE FROM association_employees WHERE sponsor_id IS NOT NULL AND sponsor_id NOT IN (SELECT id FROM sponsors);
SET FOREIGN_KEY_CHECKS = 0;
ALTER TABLE association_employees DROP FOREIGN KEY IF EXISTS association_employees_sponsor_id_foreign;
SET FOREIGN_KEY_CHECKS = 1;
ALTER TABLE association_employees ADD CONSTRAINT association_employees_sponsor_id_foreign FOREIGN KEY (sponsor_id) REFERENCES sponsors(id) ON DELETE CASCADE;
```

----------------------------

بعد تنفيذ الحل:
----------------------------

```bash
# 1. حذف Migration القديمة
php remove_migration.php

# 2. تنفيذ Migrations
php artisan migrate --force

# 3. تحديث Cache
php artisan route:cache
php artisan config:cache
```

----------------------------

إذا ظهر خطأ "Duplicate column":
----------------------------

```bash
# حل سريع
mysql -u root -p aso -e "DELETE FROM migrations WHERE migration = '2025_12_02_035205_add_sponsor_id_to_association_employees';"
php artisan migrate --force
```
