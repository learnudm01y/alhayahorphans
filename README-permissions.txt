# إذا كنت تستخدم Windows، لا تستخدم أمر chmod.
# بدلاً من ذلك، اتبع الخطوات التالية لإعطاء صلاحيات الكتابة لمجلد storage و bootstrap/cache:

1. افتح مستكشف الملفات (File Explorer).
2. انتقل إلى مجلد مشروعك ثم إلى:
   - storage
   - bootstrap\cache

3. اضغط بزر الفأرة الأيمن على المجلد واختر "Properties" (خصائص).
4. انتقل إلى تبويب "Security" (الأمان).
5. اضغط على "Edit..." (تعديل).
6. اختر اسم المستخدم الذي يشغل السيرفر (مثل IIS_IUSRS أو SYSTEM أو المستخدم الحالي).
7. فعّل خيار "Modify" و "Write" (تعديل وكتابة).
8. اضغط OK لحفظ التغييرات.

# إذا كنت تستخدم XAMPP أو Laragon أو WAMP، غالباً المستخدم هو SYSTEM أو Everyone.
# بعد ذلك، نفذ الأمر التالي في PowerShell أو CMD لإنشاء الرابط الرمزي (من مجلد المشروع):

php artisan storage:link

# الآن يجب أن يستطيع Laravel الكتابة إلى storage و public/storage.

# رسالة الخطأ تعني أن الرابط الرمزي public/storage موجود بالفعل.
# لا داعي لتنفيذ php artisan storage:link مرة أخرى إلا إذا كنت تريد إعادة إنشائه.

# إذا كنت تواجه مشاكل في الوصول أو الكتابة إلى الملفات:
# 1. تأكد أن مجلد storage/app/public لديه صلاحيات الكتابة (راجع تعليمات الصلاحيات السابقة).
# 2. إذا أردت إعادة إنشاء الرابط الرمزي (مثلاً إذا كان تالفاً)، احذفه أولاً:

# في PowerShell أو CMD (من مجلد المشروع):
rmdir public\storage

# ثم أعد تنفيذ:
php artisan storage:link

# إذا لم يكن لديك مشاكل في رفع الملفات أو الوصول إليها، تجاهل هذه الرسالة.
