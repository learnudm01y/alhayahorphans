تم حل مشكلة الملفات المكررة

تم إصلاح مشكلة Unique Constraint بنجاح!

الآن يمكن رفع نفس الملف عدة مرات بدون أخطاء، مع التحقق الذكي من الملفات المكررة.

المشكلة السابقة

خطأ SQL:

SQLSTATE[23000]: Integrity constraint violation:
1062 Duplicate entry 'cce26717fd3b20a3d29af124c30dd5b0'
for key 'enhanced_attachments_file_hash_unique'

السبب:

  • عمود file_hash له قيد فريد
  • عند رفع نفس الملف مرتين يحدث تضارب
  • النظام يحاول إدراج hash مكرر
الحل المطبق

خوارزمية التحقق الذكي:

  1. حساب hash للملف المرفوع
  2. البحث عن ملف بنفس الـ hash
  3. إذا وُجد: تحديث السجل الموجود
  4. إذا لم يوجد: إنشاء سجل جديد
النتيجة: لا مزيد من أخطاء الملفات المكررة!
